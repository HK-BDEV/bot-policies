# SimpleHelper Privacy Policy

_Last updated: 9 October 2026_

SimpleHelper ("the bot") is a Discord bot that helps players of the EPIC RPG game bot. This policy explains what data the bot uses and why.

## What the bot reads
- **Messages from the EPIC RPG bot** in channels the bot can see, to detect dungeons, enchant results and similar game events, and to suggest the next move.
- **Messages from users** that start with the bot's prefix (`p`) or are list commands (for example `join` or `fight L42`), so it can respond to commands.
- **Direct messages** sent to the bot.

Message content is processed in memory only to produce a response. It is not saved.

## What the bot stores
- Discord user IDs and channel IDs for the private-channel system (which user owns or is invited to which channel).
- Discord user IDs of players in arena, miniboss and gladiator lists while a list is running.
- The enchant a user registered with the `enchant` command, until they get it.

No passwords, emails, payment details or message history are stored.

## How data is used and shared
- Data is used only to provide the bot's features.
- Direct messages sent to the bot (text and attachment links) are forwarded to the bot's developer so they can provide support.
- When a dungeon starts in a helper channel, the developer receives a link to that message so they can monitor the helper.
- Data is never sold, and never shared with third parties except Discord itself.

## Keeping and deleting data
Stored data is kept until it is no longer needed: for example, when a channel is deleted, a list ends or an enchant is obtained. You can ask for your data to be deleted at any time by contacting us below.

## Contact
Open an issue at [github.com/HK-BDEV/bot-policies/issues](https://github.com/HK-BDEV/bot-policies/issues) for questions or data deletion requests.

## Changes
We may update this policy. The date at the top shows the latest version.
